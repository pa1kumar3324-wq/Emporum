# Emporum Landing Page

Emporum is an independent product engineering studio building custom software and digital products around real problems.

## Brand
- Premium charcoal, warm ivory and restrained antique gold
- Manrope and DM Mono typography
- Three-bar architectural mark
- Clear, studio-led positioning without forcing a single industry into every section

## Proof point
The hero card highlights **3 projects commissioned**.

## Run locally
Open `index.html` in a browser. No build step is required.

## Before publishing
Confirm that the “3 projects commissioned” statement is accurate, verify the contact email, and check the site at desktop and mobile widths.
